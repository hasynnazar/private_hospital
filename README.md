# Private Hospital Management System 🏥

## Project Overview
This is a full-stack web application designed for private medical clinics to streamline the appointment booking process. The system features role-based access for Administrators, Doctors, and Patients.

### Key Features:
* **AI-Powered Triage**: A smart chatbot assistant that helps patients identify the right specialist based on their symptoms.
* **Automated Appointment Management**: Visits are automatically set to 'Active' upon booking and transition to 'Completed' after 24 hours.
* **Role-Based Access Control (RBAC)**: Distinct interfaces and permissions for Patients, Doctors, and Admins.
* **Email Notifications**: Automatic confirmation emails for patients and schedule updates for doctors.

### Tech Stack:
* **Backend**: Java, Spring Boot, Spring Data JPA, Spring Security.
* **Frontend**: React.js.
* **Database**: MySQL.
* **AI Integration**: OpenAI API / Spring AI.
